# Sistema de Pedidos Online

Aplicação web para pedidos online feita com **HTML, CSS e JavaScript**. O usuário vê o catálogo, adiciona itens ao carrinho, confere o total e finaliza o pedido.

Projeto da lanchonete fictícia **IFOOD EXPRESS**.

## Objetivo

Facilitar a escolha e a solicitação de produtos por meio de uma plataforma digital simples e intuitiva, para consumidores e pequenos estabelecimentos que ainda dependem de pedidos presenciais ou manuais.

## Tecnologias

| Tecnologia | Uso |
|---|---|
| HTML | Estrutura das páginas, catálogo, carrinho e formulário |
| CSS | Cores, fontes, botões, organização dos elementos e responsividade |
| JavaScript | Carrinho, quantidades, cálculo do total e confirmação do pedido |

## Funcionalidades

- [x] Página inicial
- [x] Catálogo de produtos (imagem, nome, descrição e preço)
- [x] Categorias de produtos
- [x] Carrinho de compras (adicionar e remover)
- [x] Controle de quantidade (+ e −)
- [x] Cálculo automático do total
- [x] Formulário de pedido
- [x] Resumo do pedido
- [x] Confirmação do pedido
- [x] Design responsivo

# Diário de desenvolvimento

- **Dia 1:** página inicial com HTML e CSS externo.
- **Dia 2:** catálogo com produtos separados por categoria e imagens.
- **Dia 3:** carrinho, controle de quantidade, total automático, formulário, resumo e confirmação (`js/script.js` e `css/carrinho.css`).
